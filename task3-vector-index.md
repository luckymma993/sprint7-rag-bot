## Модель эмбеддингов

| Параметр | Значение |
|---|---|
| Название | `intfloat/multilingual-e5-base` |
| Где взять | [huggingface.co/intfloat/multilingual-e5-base](https://huggingface.co/intfloat/multilingual-e5-base), библиотека Sentence-Transformers |
| Размер вектора | **768** чисел |
| Размер модели | около 1,1 ГБ, 278 млн параметров |
| Языки | более 100, включая русский и английский |
| Лимит текста | 512 токенов |

Выбрана в задании 1: бесплатная, работает локально, понимает русские вопросы к английским документам. Модель эмбеддингов не заменяет нейросеть, которая пишет ответ: она только превращает текст в числа для поиска.

## Как устроена индексация

1. **Нарезка на чанки.** Используется `RecursiveCharacterTextSplitter` из LangChain. Размер чанка 240 слов, перекрытие между соседними 40 слов (чтобы мысль не обрывалась на границе). Режет сначала по абзацам, потом по предложениям, потом по словам. Совсем короткие обрывки (меньше 60 слов) приклеиваются к соседнему чанку.
2. **Метаданные.** У каждого чанка сохраняются: номер `id` (он же номер строки в индексе), путь к файлу `source`, заголовок документа `title`, путь по заголовкам внутри документа `section` (например, `Yarwyn Daelthos > Biography > Early life`), номер чанка в документе, позиция начала в файле `start` и число слов. Позиция и источник нужны, чтобы бот мог ссылаться на источник в ответе.
3. **Эмбеддинги.** Перед превращением в вектор к чанку добавляется заголовок документа и раздела. Так кусок вроде «Он родился на пустынной планете…» знает, о ком идёт речь. Модель e5 требует префиксов: `passage: ` для чанков и `query: ` для вопросов. Векторы нормализуются, поэтому скалярное произведение равно косинусной близости.
4. **Индекс.** `faiss.IndexFlatIP`: точный поиск по всем 471 вектору. Для такого размера приближённые индексы не нужны, точный работает быстрее и без потери качества. При росте до сотен тысяч чанков его нужно заменить на HNSW или IVF.
5. **Поиск.** Вопрос получает префикс `query: `, превращается в вектор, и индекс возвращает ближайшие чанки с оценками.

## Проверка качества

Проверено на 8 вопросах: 5 на русском и 3 на английском. Для каждого заранее выбран документ, где лежит ответ.

| Вопрос | Нужный документ первым | В первых трёх | Ответ в найденных чанках |

| Что такое Void Core и какое оружие на нём было? | да | да | да |

| Какая ледяная планета является родиной вида snowfang? | да | да | да |
| Which planet has two suns and moisture farms? | да | да | да |
| How did the Vastrian Dominion fall after Ursera Bregoth died? | **нет** | да | **нет** |
| Кто такой Tevzek Caenor и почему он покинул орден Salphos? | да | да | да |
| **Итого** | **6 из 8** | **7 из 8** | **7 из 8** |

**Два промаха.**

- *Плазменный клинок.* Нашлись статьи про кристалл `ixium`, из которого клинок сделан, и про гиперпривод. Нужный документ `plasmablade.md` не попал в тройку, но слово из ответа в найденном тексте есть: статья про кристалл тоже отвечает на вопрос частично.
- *Падение Dominion.* Первым оказался документ о самом Dominion, а нужный `ascendant-directorate.md` второй. Фрагмент с ответом не попал в тройку.

Строгая оценка оставлена как есть, чтобы не завышать результат.

## Вопросы, на которые в базе ответа нет

| Вопрос | Лучшая оценка | Что нашлось |
|---|---|---|
| Как приготовить борщ? | 0,733 | случайные биографии |
| Who is Darth Vader? (исходное имя заменено) | 0,789 | введение в документ о `Yarwyn Daelthos` |
| Расскажи про Люка Скайуокера и планету Татуин | 0,796 | случайные чанки и документ о `Tevlan` |

**Вывод, важный для бота.** Оценки у вопросов с ответом (0,75–0,87) и без ответа (0,73–0,80) пересекаются. Модель e5 даёт сжатый диапазон оценок, поэтому по одному порогу нельзя надёжно решить «в базе ничего нет». В задании 4 «Я не знаю» будет строиться на двух вещах: низкий порог оценки (около 0,74) отсекает явный мусор вроде борща, а инструкция в промпте велит модели отвечать «Я не знаю», если в найденных фрагментах нет ответа.

## Как запустить

```bash
.venv\Scripts\python build_index.py
.venv\Scripts\python search_index.py "На какой планете родился Yarwyn Daelthos?" -k 3
.venv\Scripts\python eval_index.py
```

Нужны пакеты `faiss-cpu`, `sentence-transformers`, `langchain-text-splitters`, `numpy`. Модель скачивается с Hugging Face при первом запуске (около 1,1 ГБ) и дальше берётся из кеша.

## Что нужно помнить

- Индекс привязан к модели: при смене модели его нужно пересобрать.
- Индекс привязан к базе знаний: если заново запустить сборку базы из задания 2, случайные имена изменятся. Тогда придётся пересобрать индекс и обновить вопросы.
- Бот в задании 4 использует те же `index_common.py` и индекс, ничего не меняя.
